Forkspaces

Forkspaces creates isolated spaces for Claude Desktop. Each space opens as its own macOS app with its own sign-in, history and settings. The original Claude is never modified.

Spaces

New Space starts empty, from your existing Claude installation, or from another space. Duplicate Space makes an independent copy. Import Space Data replaces a space's Claude data with a copy from another source; the previous data is backed up first.

Open, Stop and edit

Stop asks only that space to quit normally. Close a space before editing, importing into it or deleting it. Changing the icon or color only updates its launcher; renaming rebuilds it. Claude data is never touched by these actions.

Export and import

Export Space saves a space's Claude data, name, color and icon to a disk image encrypted with a password you choose. The space must be closed while exporting. The export includes the active sign-in: keep it private, since anyone with the file and the password can use that account. Import creates a new space from an export; existing spaces are not changed. On another Mac you may need to sign in again, because Claude keeps some encryption keys in the Keychain of the Mac where the space was created.

Where things live

Space data: ~/Library/Application Support/Forkspaces/profiles/
Launchers: ~/Applications/Forkspaces/
Deleted spaces and import backups: ~/Library/Application Support/Forkspaces/Backups/
The size shown for each space is its data folder. Launchers are APFS clones of Claude and share most of their disk space with it.

After updating Claude

Each space uses its own copy of Claude. After Claude updates, use Rebuild from Claude on each space; its data is kept.

Built-in browser

Rebuild existing spaces after updating Forkspaces to restore Cowork’s computer connection. Each space now runs an intact, Anthropic-signed copy of Claude; the original app can stay closed. Open spaces through Forkspaces or their named launcher apps. The inner app keeps Claude’s official name and icon. Pin the named launcher to the Dock, not the inner Claude app: opening the inner app directly does not select your space’s data folder.

Cowork storage

Close two spaces with Cowork installed, then choose Optimize Cowork Storage from a space's menu. Matching VM image blocks are shared using APFS; each space keeps its own contents and independent writes. Updated launchers also try this on a later launch after the initial download. Rebuild existing spaces to enable that behavior. File sizes include shared blocks; free disk space may recover later if APFS snapshots retain the old image.

Sign-in

Sign in inside each space as usual. If the browser returns to the wrong space, use Sign-in Help to route the login to that space, then restore the previous routing.

Privacy and limits

Everything runs locally. Forkspaces has no account, backend or telemetry and never reads chats, cookies or tokens. Spaces separate accounts; they are not a security sandbox — all spaces run as your macOS user, and some system logs and services stay shared.

Icon styles

Space icons keep their color with the default icon style. With Icon & widget style: Dark or Tinted (System Settings → Appearance), macOS restyles them and the chosen color is lost. Colored dark variants need a compiled icon catalog, which only Xcode can build, and each space's icon is generated on your Mac. Tinted style removes color from every app by design.
